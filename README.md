
# HackGeniX – Company Website

A responsive company website created as part of the HackGeniX web development training project.

## Features

- Responsive navigation bar
- Hero section
- Company introduction
- Three service cards
- Testimonials section
- Contact section
- Footer
- Responsive layout for desktop, tablet and mobile

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- CSS Transitions

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
